# CRM Customization Bootcamp
## The Repo
This REPO goes along with the **6-week HubSpot Academy Bootcamp**. 
You will start using this REPO during weeks 2 - 6. You will need to FORK this REPO.

## Bootcamp
If you found this REPO and you're interested in signing up for the bootcamp, you can find more details here.

[Click here](https://www.hubspot.com/academy/bootcamps/crmcb) to learn more about the HubSpot Academy CRM Customization Bootcamp for Developers.

## Help
[HubSpot Developer Slack Community](https://developers.hubspot.com/slack)
This will be your best friend and also an awesome place of community. 

## File Structure
- data - All the data you need to import into your developer test account.
- cards - A couple of different cards to show you how you can get started. Built on platform version **2026.09**.
- week-2 - Understand the problem before you build: problem brief, mockup, build plan, and a one-shot card to compare against.
- .claude/skills/hubspot-card-design - A Claude Code skill with the design rules for cards that look and feel like HubSpot (uses [hs-uix](https://github.com/05bmckay/hs-uix)). Claude Code picks it up automatically when you open this repo.

## Requirements
- [HubSpot CLI](https://github.com/HubSpot/hubspot-cli/) v8.16.0 or newer (`npm install -g @hubspot/cli@latest`)
- Node.js 20 or newer
- A HubSpot developer test account (serverless functions won't upload to non-Enterprise standard accounts)
- Your favorite editor, VS Code, Zed.dev, Notepad++
- Optional: [Claude Code](https://claude.com/claude-code) or another AI coding agent, with the HubSpot Developer MCP (`hs mcp setup`, run inside your project folder)
